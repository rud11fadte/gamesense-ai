# 🎮 GameSense AI

## Player Churn Prediction using Machine Learning

GameSense AI is a machine learning project designed to predict whether a player is likely to churn based on their gaming behavior and player telemetry.

## Project Objective

The objective of this project is to develop a supervised machine learning classification system that can identify players who are at risk of churn.

## Problem Statement

Gaming companies collect large amounts of player behavior data. Identifying players who are likely to stop playing can help game developers improve player retention and engagement.

GameSense AI uses player behavior data to predict player churn.

## Machine Learning Task

This is a binary classification problem.

- `False` → Player is not churned
- `True` → Player is churned
